# Курсовая / проект: Умный будильник для Android

Приложение будильника с расписанием. Написано на Kotlin в Android Studio.

## Что умеет:
- Ставить будильники по дням
- Звонит даже если телефон заблокирован (использовал `AlarmManager.setAlarmClock`, чтобы система не выгружала)
- Поверх экрана блокировки включается экран со звуком и вибрацией
- Есть задачка по математике для пробуждения
- Читает уведомления (`NotificationListenerService`) и выводит на экран

## Запуск:
Открыть папку в Android Studio, подождать и нажать Run.
На 13+ андроиде нужно дать разрешение на уведомления и точные будильники (в самом приложении).
